# ctp-base 接口说明

本文列出 `ctp-base` 当前公开接口与 CTP C++ 接口的对应关系，避免直接使用 C++ 名称时找不到 Rust 方法。

## 命名约定

- CTP `ReqUserLogin` 对应 Rust `login`；
- CTP `ReqQryInstrument` 对应 Rust `query_instrument`；
- CTP `ReqOrderInsert` 对应 Rust `insert_order`；
- CTP `RegisterFront` 对应 Rust `register_front`；
- CTP `Release` 不在 Rust 中公开同名方法，由 `close()` 通过所有权自动释放；
- CTP `RegisterSpi` 由 `MdApi::new` / `TraderApi::new` 内部完成。

请求转换失败会直接返回 `ConversionError`；回调负载 owned 化失败会调用 SPI 的 `conversion_error`。

## 行情配置

### `MdConfig`

| 字段 | 类型 | 作用 |
|---|---|---|
| `flow_path` | `String` | CTP 流量文件目录 |
| `using_udp` | `bool` | 是否使用 UDP 行情 |
| `multicast` | `bool` | 是否使用组播行情 |
| `production_mode` | `bool` | 生产或测评模式 |

`MdConfig::new(flow_path)` 默认关闭 UDP、组播，并启用生产模式。

## 行情 API

### `MdApi`

| Rust 方法 | 参数 | 返回 | CTP 接口 | 作用 |
|---|---|---|---|---|
| `new` | `config: MdConfig, spi: Box<dyn MdSpi>` | `Result<MdApi, CreateMdApiError>` | `CreateFtdcMdApi` + `RegisterSpi` | 创建行情 API 并注册 SPI |
| `version` | `&self` | `String` | `GetApiVersion` | 获取 API 版本 |
| `init` | `&self` | `()` | `Init` | 启动原生工作线程 |
| `join` | `&self` | `i32` | `Join` | 等待原生线程退出 |
| `trading_day` | `&self` | `String` | `GetTradingDay` | 获取当前交易日 |
| `register_front` | `address: &str` | `Result<(), ConversionError>` | `RegisterFront` | 注册行情前置地址 |
| `register_name_server` | `address: &str` | `Result<(), ConversionError>` | `RegisterNameServer` | 注册名字服务器地址 |
| `register_fens_user_info` | `request: &FensUserInfo` | `Result<(), ConversionError>` | `RegisterFensUserInfo` | 注册 Fens 用户信息 |
| `subscribe` | `instruments: &[&str]` | `Result<i32, ConversionError>` | `SubscribeMarketData` | 订阅行情 |
| `unsubscribe` | `instruments: &[&str]` | `Result<i32, ConversionError>` | `UnSubscribeMarketData` | 退订行情 |
| `subscribe_quote` | `instruments: &[&str]` | `Result<i32, ConversionError>` | `SubscribeForQuoteRsp` | 订阅询价 |
| `unsubscribe_quote` | `instruments: &[&str]` | `Result<i32, ConversionError>` | `UnSubscribeForQuoteRsp` | 退订询价 |
| `login` | `request: &ReqUserLogin, request_id: i32` | `Result<i32, ConversionError>` | `ReqUserLogin` | 登录行情前置 |
| `logout` | `request: &UserLogout, request_id: i32` | `Result<i32, ConversionError>` | `ReqUserLogout` | 登出行情前置 |
| `query_multicast_instrument` | `request: &QryMulticastInstrument, request_id: i32` | `Result<i32, ConversionError>` | `ReqQryMulticastInstrument` | 查询组播合约 |
| `close` | `self` | `()` | `Release` | 释放本地原生 API |

## 交易配置

### `TraderConfig`

| 字段 | 类型 | 作用 |

`TraderConfig::new(flow_path)` 默认启用生产模式。

## 共享交易句柄

### `SharedTraderApi`

`SharedTraderApi` 通过 `Deref` 复用 `TraderApi` 的请求方法，用于在保持生命周期控制的前提下共享原生 API。配置、初始化与释放仍由外层生命周期管理。

## SPI

使用方实现 `MdSpi` 或 `TraderSpi`：

```rust
impl MdSpi for MySpi {
    fn tick(&mut self, data: Option<DepthMarketData>) {
        // 处理行情
    }
}
```

回调参数已经 owned 化；只有需要记录桥接层数据质量问题时才实现 `conversion_error`。
